# TeleBox

A modern, real-time chat application built with Node.js and React. TeleBox enables users to communicate instantly through individual chats and group conversations with a seamless, responsive interface.

## 🎯 Features

- **User Authentication**: Secure sign-up and sign-in with JWT-based authentication
- **Real-Time Messaging**: Instant message delivery using WebSocket (Socket.io)
- **Chat Management**: Create and manage individual chats and group conversations
- **User Profiles**: User profile management and customization
- **File Sharing**: Upload and share files via AWS S3 integration
- **Responsive UI**: Modern, mobile-friendly interface built with React and Tailwind CSS
- **Containerized Deployment**: Docker and Docker Compose support for easy deployment

## 📋 Tech Stack

### Backend
- **Runtime**: Node.js
- **Framework**: Express.js v5.1.0
- **Database**: MongoDB with Mongoose ODM
- **Authentication**: JWT (JSON Web Tokens) with bcrypt password hashing
- **Real-Time Communication**: Socket.io v4.8.1
- **File Storage**: AWS S3

### Frontend
- **Framework**: React 19.1.1
- **Build Tool**: Vite 7.1.2
- **Styling**: Tailwind CSS 4.1.12
- **Routing**: React Router DOM 7.8.2
- **State Management**: React Query (TanStack Query) v5.90.3
- **Real-Time Client**: Socket.io Client v4.8.1
- **HTTP Client**: Axios v1.11.0
- **Linting**: ESLint 9.33.0

### DevOps
- **Containerization**: Docker
- **Orchestration**: Docker Compose
- **Image Registry**: Amazon ECR
